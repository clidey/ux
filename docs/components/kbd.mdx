A visual keyboard key cap component for displaying keyboard shortcuts. Purely presentational; it does not bind any keyboard listeners or register shortcuts.


## Interactive example

<Specimen label="Kbd · Live example" padding="none">
  <KbdPreview />

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo } from "./demo-shell";

export function KbdPreview() {
  const [platform, setPlatform] = useState("mac");
  return (
    <Demo hint="Change platforms to see how shortcut labels adapt.">
      <div className="ux-demo-row">
        <UX.Kbd>{platform === "mac" ? "⌘" : "Ctrl"}</UX.Kbd>
        <UX.Kbd>K</UX.Kbd>
        <span>Open command search</span>
      </div>
      <UX.Button
        variant="outline"
        onClick={() => setPlatform(platform === "mac" ? "windows" : "mac")}
      >
        Show {platform === "mac" ? "Windows" : "macOS"} shortcut
      </UX.Button>
    </Demo>
  );
}
```
</Specimen>

The code uses shared demo presentation helpers. Their complete source and styling are included in [the LLM build context](/llms.txt).


## Usage

```tsx
import { Kbd } from '@clidey/ux';

function ShortcutHint() {
  return (
    <div className="flex items-center gap-1">
      <Kbd>⌘</Kbd><Kbd>K</Kbd>
      <span className="text-sm text-muted-foreground ml-2">Open search</span>
    </div>
  );
}
```

## Props

`Kbd` extends all native `<kbd>` element attributes.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | The key label to display (e.g., "⌘", "Shift", "K") |
| `className` | `string` | — | Additional CSS classes |

## Examples

### Single key
```tsx
<Kbd>Esc</Kbd>
```

### Key combination
```tsx
<div className="flex items-center gap-1">
  <Kbd>⌘</Kbd><Kbd>⇧</Kbd><Kbd>P</Kbd>
</div>
```

<Note>
  This component is purely visual. To actually register keyboard shortcuts, use `addEventListener('keydown', ...)` or a shortcut library separately.
</Note>
