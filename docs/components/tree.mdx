`Tree` renders a hierarchical data structure with expand/collapse, keyboard navigation, and type-ahead search. Common use cases include file explorers, category trees, and nested menu structures. Selected items are indicated with a semibold label and accent background. Focused items show a ring indicator.

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo, Status } from "./demo-shell";

const files: UX.TreeDataItem[] = [

    name: "Workspace",
    children: [
      {
        id: "design",
        name: "Design",
        children: [
          { id: "tokens", name: "tokens.css" },
          { id: "components", name: "components.tsx" },
        ],
      },
      {
        id: "notes",
        name: "Notes",
        children: [
          { id: "readme", name: "README.md" },
          { id: "roadmap", name: "roadmap.md" },
        ],
      },
    ],
  },
];

export function TreePreview() {
  const [expanded, setExpanded] = useState(["workspace", "design"]);
  const [selected, setSelected] = useState("tokens.css");
  return (
    <Demo hint="Expand folders, choose a file, or collapse the whole tree.">
      <div className="ux-demo-tree">
        <UX.Tree
          data={files}
          expandedIds={expanded}
          onExpandChange={setExpanded}
          initialSelectedItemId="tokens"
          onSelectChange={(item) => setSelected(item?.name ?? "Nothing selected")}
        />
      </div>
      <div className="ux-demo-row">
        <UX.Button variant="outline" onClick={() => setExpanded(["workspace", "design", "notes"])}>
          Expand all
        </UX.Button>
        <UX.Button variant="ghost" onClick={() => setExpanded([])}>
          Collapse all
        </UX.Button>
      </div>
      <Status>Selected: {selected}</Status>
    </Demo>
  );
}
```

## Import

```tsx
import { Tree } from '@clidey/ux';
import type { TreeDataItem } from '@clidey/ux';
```

## Basic tree

```tsx
const treeData: TreeDataItem[] = [
  {
    id: '1',
    name: 'src',
    children: [
      {
        id: '1-1',
        name: 'components',
        children: [
          { id: '1-1-1', name: 'Button.tsx' },
          { id: '1-1-2', name: 'Card.tsx' },
          { id: '1-1-3', name: 'Input.tsx' },
        ],
      },
      {
        id: '1-2',
        name: 'lib',
        children: [
          { id: '1-2-1', name: 'utils.ts' },
          { id: '1-2-2', name: 'api.ts' },
        ],
      },
    ],
  },
  { id: '2', name: 'package.json' },
  { id: '3', name: 'tsconfig.json' },
];

<Tree data={treeData} />
```

## With selection

```tsx
function FileExplorer() {
  const [selected, setSelected] = useState<TreeDataItem | undefined>();

  return (
    <div className="flex gap-4">
      <div className="w-56 border rounded-lg p-2">
        <Tree
          data={treeData}
          onSelectChange={setSelected}
        />
      </div>
      <div className="flex-1 p-4">
        {selected ? (
          <p>Selected: <code>{selected.name}</code></p>
        ) : (
          <p className="text-muted-foreground">Select a file</p>
        )}
      </div>
    </div>
  );
}
```

## Expand all by default

```tsx
<Tree data={treeData} expandAll />
```

## Custom icons

Override the default folder and item icons:

```tsx
import { IconFolder as Folder, IconFileText as FileText } from '@clidey/ux';

<Tree
  data={treeData}
  folderIcon={Folder}
  itemIcon={FileText}
/>
```

## With per-item icons

Set an `icon` on individual `TreeDataItem` entries:

```tsx
import { IconFileCode as FileJson, IconFileCode as FileCode, IconFolder as FolderOpen } from '@clidey/ux';

const treeData: TreeDataItem[] = [
  {
    id: '1',
    name: 'src',
    icon: FolderOpen,
    children: [
      { id: '1-1', name: 'index.ts', icon: FileCode },
      { id: '1-2', name: 'config.json', icon: FileJson },
    ],
  },
];
```

## Keyboard navigation

Click inside the tree to focus it, then use keyboard shortcuts:

| Key | Action |
| --- | --- |
| `↑` / `↓` | Move focus between visible nodes |
| `→` | Expand collapsed folder, or move to first child |
| `←` | Collapse expanded folder, or move to parent |
| `Enter` / `Space` | Select the focused node |
| `Home` / `End` | Jump to first / last visible node |
| Type a letter | Jump to next node whose name starts with that character |

Type-ahead resets after 500ms of inactivity, allowing multi-character search (e.g., type "re" to jump to "Reports").

## Controlled expand/collapse

Control which nodes are expanded externally (useful for search filtering):

```tsx
function SearchableTree() {
  const [expandedIds, setExpandedIds] = useState<string[]>([]);

  return (
    <Tree
      data={treeData}
      expandedIds={expandedIds}
      onExpandChange={setExpandedIds}
    />
  );
}
```

## Props

### Tree

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `TreeDataItem[] \| TreeDataItem` | — | The tree data to render. |
| `initialSelectedItemId` | `string` | — | ID of the item selected on initial render. |
| `onSelectChange` | `(item: TreeDataItem \| undefined) => void` | — | Called when the selected item changes. |
| `expandAll` | `boolean` | `false` | Expands all nodes on initial render. |
| `expandedIds` | `string[]` | — | Controlled expanded node IDs. |
| `onExpandChange` | `(ids: string[]) => void` | — | Called when expand state changes. |
| `folderIcon` | `LucideIcon` | — | Custom icon for folder nodes. |
| `itemIcon` | `LucideIcon` | — | Custom icon for leaf nodes. |
| `className` | `string` | — | Additional CSS classes. |

### TreeDataItem type

```tsx
type TreeDataItem = {
  id: string;
  name: string;
  icon?: LucideIcon;
  children?: TreeDataItem[];
};
```

<Note>
  Keyboard navigation follows the WAI-ARIA treeview pattern. Focus remains on the tree container; individual nodes are highlighted via `aria-activedescendant`.
</Note>
