`Spinner` is an animated circular loader with 5 color variants and flexible sizing options.


## Interactive example

<Specimen label="Spinner · Live example">
  <SpinnerPreview />

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo, Status } from "./demo-shell";

export function SpinnerPreview() {
  const [running, setRunning] = useState(true);
  const [size, setSize] = useState<"sm" | "default" | "lg">("default");
  return (
    <Demo hint="Change the spinner size and complete the task to stop the loading state.">
      <div className="ux-demo-row">
        {running ? <UX.Spinner size={size} /> : <UX.CatalogIcon name="check-circle" size={24} />}
        <Status>{running ? "Preparing your workspace…" : "Workspace ready"}</Status>
      </div>
      <div className="ux-demo-row">
        <UX.Select value={size} onValueChange={(v) => setSize(v as typeof size)}>
          <UX.SelectTrigger aria-label="Spinner size">
            <UX.SelectValue />
          </UX.SelectTrigger>
          <UX.SelectContent>
            <UX.SelectItem value="sm">Small</UX.SelectItem>
            <UX.SelectItem value="default">Default</UX.SelectItem>
            <UX.SelectItem value="lg">Large</UX.SelectItem>
          </UX.SelectContent>
        </UX.Select>
        <UX.Button variant="outline" onClick={() => setRunning(!running)}>
          {running ? "Complete task" : "Start task"}
        </UX.Button>
      </div>
    </Demo>
  );
}
```
</Specimen>

The code uses shared demo presentation helpers. Their complete source and styling are included in [the LLM build context](/llms.txt).


## Import

```tsx
import { Spinner } from '@clidey/ux';
```

## Variants

```tsx
<Spinner variant="default" />
<Spinner variant="primary" />
<Spinner variant="secondary" />
<Spinner variant="destructive" />
<Spinner variant="muted" />
```

| Variant | Color |
| --- | --- |
| `default` | Foreground color |
| `primary` | Primary brand color |
| `secondary` | Secondary background |
| `destructive` | Red/destructive color |
| `muted` | Muted foreground |

## Sizes

```tsx
<Spinner size="sm" />    {/* 16px */}
<Spinner size="default" /> {/* 20px */}
<Spinner size="lg" />    {/* 32px */}
<Spinner size={48} />    {/* custom px */}
```

## Inside a button

```tsx
<Button disabled>
  <Spinner size="sm" variant="default" />
  Loading...
</Button>
```

## Full-page loading

```tsx
function LoadingScreen() {
  return (
    <div className="flex items-center justify-center min-h-screen">
      <Spinner size="lg" variant="primary" />
    </div>
  );
}
```

## Inline loading in content

```tsx
function DataSection() {
  const { data, loading } = useData();

  if (loading) {
    return (
      <div className="flex items-center gap-2 text-muted-foreground">
        <Spinner size="sm" variant="muted" />
        <span>Loading...</span>
      </div>
    );
  }

  return <div>{/* render data */}</div>;
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "primary" \| "secondary" \| "destructive" \| "muted"` | `"default"` | Color variant. |
| `size` | `"sm" \| "default" \| "lg" \| number` | `"default"` | Spinner size. Pass a number for custom pixel size. |
| `className` | `string` | — | Additional CSS classes. |
