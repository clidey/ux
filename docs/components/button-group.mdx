`ButtonGroup` connects multiple buttons visually by removing the gap between them and sharing border-radius at the joints. Use it for toolbars, segmented controls, and action sets.


## Interactive example

<Specimen label="Button Group · Live example" padding="none">
  <ButtonGroupPreview />

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo, Status } from "./demo-shell";

export function ButtonGroupPreview() {
  const [view, setView] = useState("Week");
  const [vertical, setVertical] = useState(false);
  return (
    <Demo hint="Switch the selected range and change the direction of the connected control.">
      <div className="ux-demo-row">
        <UX.ButtonGroup orientation={vertical ? "vertical" : "horizontal"}>
          {["Day", "Week", "Month"].map((item) => (
            <UX.Button
              key={item}
              variant={view === item ? "secondary" : "outline"}
              aria-pressed={view === item}
              onClick={() => setView(item)}
            >
              {item}
            </UX.Button>
          ))}
        </UX.ButtonGroup>
        <UX.Button variant="ghost" onClick={() => setVertical(!vertical)}>
          Use {vertical ? "horizontal" : "vertical"}
        </UX.Button>
      </div>
      <Status>{view} view</Status>
    </Demo>
  );
}
```
</Specimen>

The code uses shared demo presentation helpers. Their complete source and styling are included in [the LLM build context](/llms.txt).


## Import

```tsx
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from '@clidey/ux';
```

## Basic usage

```tsx
<ButtonGroup>
  <Button variant="outline">Cut</Button>
  <Button variant="outline">Copy</Button>
  <Button variant="outline">Paste</Button>
</ButtonGroup>
```

## Vertical orientation

```tsx
<ButtonGroup orientation="vertical">
  <Button variant="outline">Top</Button>
  <Button variant="outline">Middle</Button>
  <Button variant="outline">Bottom</Button>
</ButtonGroup>
```

## With separator

Use `ButtonGroupSeparator` to add a visual divider inside the group:

```tsx
<ButtonGroup>
  <Button variant="outline">Bold</Button>
  <Button variant="outline">Italic</Button>
  <ButtonGroupSeparator />
  <Button variant="outline">Align Left</Button>
  <Button variant="outline">Align Center</Button>
  <Button variant="outline">Align Right</Button>
</ButtonGroup>
```

## With label text

Use `ButtonGroupText` to insert a non-interactive label or unit inside the group:

```tsx
<ButtonGroup>
  <Input className="rounded-r-none border-r-0" placeholder="Amount" />
  <ButtonGroupText>USD</ButtonGroupText>
  <Button variant="outline">Convert</Button>
</ButtonGroup>
```

## With catalog icons

```tsx
import { Button, ButtonGroup, IconDownload, IconCopy, IconArchive } from '@clidey/ux';

<ButtonGroup>
  <Button variant="outline" size="icon" aria-label="Download"><IconDownload /></Button>
  <Button variant="outline" size="icon" aria-label="Copy"><IconCopy /></Button>
  <Button variant="outline" size="icon" aria-label="Archive"><IconArchive /></Button>
</ButtonGroup>
```

## Props

### ButtonGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction of the button group. |
| `className` | `string` | — | Additional CSS classes. |
| `children` | `ReactNode` | — | `Button`, `ButtonGroupSeparator`, or `ButtonGroupText` elements. |

### ButtonGroupSeparator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | Inherits from group | Separator direction. |
| `className` | `string` | — | Additional CSS classes. |

### ButtonGroupText

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | — | Additional CSS classes. |
| `children` | `ReactNode` | — | Text or element to display. |
