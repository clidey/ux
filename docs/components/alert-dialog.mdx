`AlertDialog` is a modal that requires an explicit user decision before proceeding. Unlike `Dialog`, it cannot be closed by clicking outside or pressing Escape — the user must click one of the action buttons. Use it for irreversible or high-consequence actions. The overlay backdrop color is controlled by the `--backdrop` CSS token (see Theming docs).

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo, Status } from "./demo-shell";

export function AlertDialogPreview() {
  const [removed, setRemoved] = useState(false);
  return (
    <Demo hint="Open the confirmation, cancel it, or remove the fictional draft.">
      <UX.AlertDialog>
        <UX.AlertDialogTrigger>
          <UX.Button variant="destructive">Remove draft</UX.Button>
        </UX.AlertDialogTrigger>
        <UX.AlertDialogContent>
          <UX.AlertDialogHeader>
            <UX.AlertDialogTitle>Remove this draft?</UX.AlertDialogTitle>
            <UX.AlertDialogDescription>
              This example changes local state only. Your real projects are untouched.
            </UX.AlertDialogDescription>
          </UX.AlertDialogHeader>
          <UX.AlertDialogFooter>
            <UX.AlertDialogCancel>Keep draft</UX.AlertDialogCancel>
            <UX.AlertDialogAction onClick={() => setRemoved(true)}>
              Remove draft
            </UX.AlertDialogAction>
          </UX.AlertDialogFooter>
        </UX.AlertDialogContent>
      </UX.AlertDialog>
      <Status>{removed ? "The demo draft was removed." : "Draft is available."}</Status>
      {removed && (
        <UX.Button variant="ghost" onClick={() => setRemoved(false)}>
          Restore demo
        </UX.Button>
      )}
    </Demo>
  );
}
```

## Basic confirmation

```tsx
<AlertDialog>
  <AlertDialogTrigger>
    <Button variant="destructive">Delete account</Button>
  </AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Are you absolutely sure?</AlertDialogTitle>
      <AlertDialogDescription>
        This action cannot be undone. Your account and all associated data will
        be permanently deleted from our servers.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction>Delete account</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## Async action

```tsx
function DeleteDialog({ onDelete }: { onDelete: () => Promise<void> }) {
  const [deleting, setDeleting] = useState(false);

  async function handleDelete() {
    setDeleting(true);
    await onDelete();
    setDeleting(false);
  }

  return (
    <AlertDialog>
      <AlertDialogTrigger>
        <Button variant="destructive" size="sm">Delete</Button>
      </AlertDialogTrigger>
      <AlertDialogContent>
        <AlertDialogHeader>
          <AlertDialogTitle>Delete this item?</AlertDialogTitle>
          <AlertDialogDescription>
            This will permanently delete the item and all related data.
          </AlertDialogDescription>
        </AlertDialogHeader>
        <AlertDialogFooter>
          <AlertDialogCancel disabled={deleting}>Cancel</AlertDialogCancel>
          <AlertDialogAction onClick={handleDelete} disabled={deleting}>
            {deleting ? (
              <>
                <Spinner size="sm" />
                Deleting...
              </>
            ) : (
              'Delete'
            )}
          </AlertDialogAction>
        </AlertDialogFooter>
      </AlertDialogContent>
    </AlertDialog>
  );
}
```

## Controlled

```tsx
const [open, setOpen] = useState(false);

<AlertDialog open={open} onOpenChange={setOpen}>
  <AlertDialogTrigger>
    <Button>Publish changes</Button>
  </AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Publish to production?</AlertDialogTitle>
      <AlertDialogDescription>
        This will immediately affect all users. Make sure you've reviewed all
        changes.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Go back</AlertDialogCancel>
      <AlertDialogAction onClick={() => { publish(); setOpen(false); }}>
        Publish
      </AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## Difference from Dialog

| Feature | Dialog | AlertDialog |
| --- | --- | --- |
| Close on overlay click | Yes | No |
| Close on Escape key | Yes | No |
| Use case | Forms, info | Confirmations, destructive actions |
| `AlertDialogAction` | — | Styled as primary action |
| `AlertDialogCancel` | — | Styled as outline/cancel |

## Sub-components

| Component | Description |
| --- | --- |
| `AlertDialog` | Root component. Manages open state. |
| `AlertDialogTrigger` | Opens the dialog. Renders as its child automatically for ux components (`Button`, `Badge`, ...) and intrinsic elements, so no `asChild` is needed; pass `asChild` only for other ref-forwarding elements. See [Triggers and asChild](/triggers-and-aschild). |
| `AlertDialogContent` | Dialog panel. |
| `AlertDialogHeader` | Container for title and description. |
| `AlertDialogTitle` | Accessible heading (required). |
| `AlertDialogDescription` | Explanatory text. |
| `AlertDialogFooter` | Action button area. |
| `AlertDialogCancel` | Dismisses the dialog without acting. |
| `AlertDialogAction` | Proceeds with the action. |
