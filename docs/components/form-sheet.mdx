A convenience wrapper around `Sheet` that provides a standard slide-out panel with title, description, and optional pinned footer. Reduces boilerplate for the common "open a side panel with a form" pattern.


## Interactive example

<Specimen label="Form Sheet · Live example">
  <FormSheetPreview />

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo, Status } from "./demo-shell";

export function FormSheetPreview() {
  const [open, setOpen] = useState(false);
  const [name, setName] = useState("Studio");
  const [saved, setSaved] = useState("Studio");
  return (
    <Demo hint="Open the form sheet, edit the name, and save to update the workspace.">
      <UX.Button variant="outline" onClick={() => setOpen(true)}>
        Edit workspace
      </UX.Button>
      <UX.FormSheet
        open={open}
        onClose={() => setOpen(false)}
        title="Edit workspace"
        description="A focused form with a pinned action."
        footer={
          <UX.Button
            onClick={() => {
              setSaved(name);
              setOpen(false);
            }}
          >
            Save workspace
          </UX.Button>
        }
      >
        <div className="ux-demo-form">
          <UX.Label htmlFor="form-sheet-name">Workspace name</UX.Label>
          <UX.Input id="form-sheet-name" value={name} onChange={(e) => setName(e.target.value)} />
        </div>
      </UX.FormSheet>
      <Status>Saved workspace: {saved}</Status>
    </Demo>
  );
}
```
</Specimen>

The code uses shared demo presentation helpers. Their complete source and styling are included in [the LLM build context](/llms.txt).


## Usage

```tsx
import { FormSheet, Button, Input, Label } from '@clidey/ux';

function CreateProjectPanel() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setOpen(true)}>New project</Button>
      <FormSheet
        open={open}
        onClose={() => setOpen(false)}
        title="Create project"
        description="Fill in the details."
        footer={<Button className="w-full">Create</Button>}
      >
        <div className="space-y-4 py-4">
          <Label>Name</Label>
          <Input placeholder="My project" />
        </div>
      </FormSheet>
    </>
  );
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | — | **Required.** Whether the sheet is open |
| `onClose` | `() => void` | — | **Required.** Called when the sheet should close |
| `title` | `string` | — | **Required.** Sheet heading |
| `description` | `string` | — | Optional subheading below the title |
| `children` | `ReactNode` | — | Form content (scrollable) |
| `side` | `"right" \| "left" \| "top" \| "bottom"` | `"right"` | Which edge the sheet slides from |
| `className` | `string` | `"w-full sm:max-w-lg..."` | Override SheetContent classes |
| `footer` | `ReactNode` | — | Pinned content at the bottom (outside scroll area) |

<Note>
  The `footer` prop renders below the scrollable content area. Use it for action buttons (Save, Cancel) that should always be visible regardless of scroll position.
</Note>
