`Sheet` is a panel that slides in from the edge of the screen. Unlike `Drawer` (which uses Vaul and supports drag gestures), `Sheet` is built on Radix UI's dialog primitive and is better suited for desktop navigation panels and detail views. The overlay backdrop color is controlled by the `--backdrop` CSS token (see Theming docs).


## Interactive example

<Specimen label="Sheet · Live example" padding="none">

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo, Status } from "./demo-shell";

export function SheetPreview() {
  const [side, setSide] = useState<"right" | "left">("right");
  const [name, setName] = useState("Studio");
  return (
    <Demo hint="Choose an edge, open the panel, and edit a workspace without leaving the page.">
      <div className="ux-demo-row">
        <UX.Select value={side} onValueChange={(x) => setSide(x as typeof side)}>
          <UX.SelectTrigger aria-label="Sheet edge">
            <UX.SelectValue />
          </UX.SelectTrigger>
          <UX.SelectContent>
            <UX.SelectItem value="right">Right edge</UX.SelectItem>
            <UX.SelectItem value="left">Left edge</UX.SelectItem>
          </UX.SelectContent>
        </UX.Select>
        <UX.Sheet>
          <UX.SheetTrigger>
            <UX.Button>Open workspace panel</UX.Button>
          </UX.SheetTrigger>
          <UX.SheetContent side={side}>
            <UX.SheetHeader>
              <UX.SheetTitle>Workspace details</UX.SheetTitle>
              <UX.SheetDescription>
                Keep the surrounding context while making a quick change.
              </UX.SheetDescription>
            </UX.SheetHeader>
            <div className="ux-demo-form ux-demo-sheet-body">
              <UX.Label htmlFor="sheet-workspace">Workspace name</UX.Label>
              <UX.Input
                id="sheet-workspace"
                value={name}
                onChange={(e) => setName(e.target.value)}
              />
            </div>
            <UX.SheetFooter>
              <UX.SheetClose asChild>
                <UX.Button>Done</UX.Button>
              </UX.SheetClose>
            </UX.SheetFooter>
          </UX.SheetContent>
        </UX.Sheet>
      </div>
      <Status>Workspace: {name}</Status>
    </Demo>
  );
}
```
</Specimen>

The code uses shared demo presentation helpers. Their complete source and styling are included in [the LLM build context](/llms.txt).


## Import

```tsx
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetDescription,
  SheetFooter,
  SheetClose,
} from '@clidey/ux';
```

## Basic sheet (right, default)

```tsx
<Sheet>
  <SheetTrigger>
    <Button variant="outline">Open panel</Button>
  </SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Edit profile</SheetTitle>
      <SheetDescription>
        Update your profile information and save.
      </SheetDescription>
    </SheetHeader>
    <div className="py-4 space-y-4">
      <div className="space-y-1">
        <Label htmlFor="name">Name</Label>
        <Input id="name" />
      </div>
      <div className="space-y-1">
        <Label htmlFor="bio">Bio</Label>
        <TextArea id="bio" />
      </div>
    </div>
    <SheetFooter>
      <SheetClose>
        <Button variant="outline">Cancel</Button>
      </SheetClose>
      <Button>Save</Button>
    </SheetFooter>
  </SheetContent>
</Sheet>
```

## Side variants

```tsx
{/* From the left */}
<SheetContent side="left">
  {/* navigation sidebar content */}
</SheetContent>

{/* From the bottom */}
<SheetContent side="bottom">
  {/* mobile action menu */}
</SheetContent>

{/* From the top */}
<SheetContent side="top">
  {/* notification center */}
</SheetContent>
```

## Sheet vs Drawer

| | Sheet | Drawer |
| --- | --- | --- |
| Library | Radix UI | Vaul |
| Drag to dismiss | No | Yes (mobile) |
| Best for | Desktop panels, forms | Mobile sheets, action menus |
| Default side | Right | Bottom |

## Sub-components

| Component | Description |
| --- | --- |
| `Sheet` | Root. Manages open state. |
| `SheetTrigger` | Opens the sheet. Renders as its child automatically for ux components (`Button`, `Badge`, ...) and intrinsic elements, so no `asChild` is needed; pass `asChild` only for other ref-forwarding elements. See [Triggers and asChild](/triggers-and-aschild). |
| `SheetContent` | The sliding panel. |
| `SheetHeader` | Top section. |
| `SheetTitle` | Accessible heading (required). |
| `SheetDescription` | Supporting text. |
| `SheetFooter` | Bottom action area. |
| `SheetClose` | Closes the sheet. Use `asChild`. |

### SheetContent Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"right"` | Which edge the sheet slides from. |
| `onClose` | `() => void` | — | Called when the sheet closes. |
| `className` | `string` | — | Additional CSS classes (e.g., custom width). |
