`Progress` is a horizontal progress bar that visually represents a completion percentage. Built on Radix UI's progress primitive.



## Interactive example

<Specimen label="Progress · Live example" padding="none">
  <FeedbackDemo />

```tsx
import { useState } from "react";
import { Button, Badge, Label, Progress, CatalogIcon, Alert, AlertTitle, AlertDescription } from "@clidey/ux";

export function FeedbackDemo() {
  const [value, setValue] = useState(35);
  return (
    <div className="ux-demo">
      <div className="ux-demo-row">
        <Badge>In progress</Badge>
        <Badge variant="secondary">Draft</Badge>
        <Badge variant="outline">Reviewed</Badge>
      </div>
      <Label>Project progress: {value}%</Label>
      <Progress value={value} aria-label="Project progress" />
      <div className="ux-demo-row">
        <Button
          variant="outline"
          disabled={value === 0}
          onClick={() => setValue((n) => Math.max(0, n - 10))}
        >
          Decrease
        </Button>
        <Button disabled={value === 100} onClick={() => setValue((n) => Math.min(100, n + 10))}>
          Advance
        </Button>
        <Button variant="ghost" onClick={() => setValue(35)}>
          Reset
        </Button>
      </div>
      {value === 100 && (
        <Alert>
          <CatalogIcon name="check-circle" />
          <AlertTitle>All done</AlertTitle>
          <AlertDescription>The progress control reached its completed state.</AlertDescription>
        </Alert>
      )}
      <p>Change the value to see progress, disabled actions, and completion feedback.</p>
    </div>
  );
}
```
</Specimen>

```tsx

```

## Controlled progress

```tsx
import { useState } from 'react';

function UploadProgress() {
  const [progress, setProgress] = useState(0);

  function startUpload() {
    // Simulate upload progress
    let p = 0;
    const interval = setInterval(() => {
      p += 10;
      setProgress(p);
      if (p >= 100) clearInterval(interval);
    }, 300);
  }

  return (
    <div className="space-y-2">
      <div className="flex justify-between text-sm">
        <span>Uploading file...</span>
        <span>{progress}%</span>
      </div>
      <Progress value={progress} />
      <button onClick={startUpload}>Start</button>
    </div>
  );
}
```

## Step completion

```tsx
const steps = ['Account', 'Profile', 'Billing', 'Done'];
const currentStep = 2; // 0-indexed

<div className="space-y-2">
  <div className="flex justify-between text-sm text-muted-foreground">
    <span>Step {currentStep + 1} of {steps.length}</span>
    <span>{steps[currentStep]}</span>
  </div>
  <Progress value={(currentStep / (steps.length - 1)) * 100} />
</div>
```

## Multiple bars

```tsx
<div className="space-y-3">
  {[
    { label: 'JavaScript', value: 85 },
    { label: 'TypeScript', value: 72 },
    { label: 'Python', value: 60 },
    { label: 'Rust', value: 35 },
  ].map((lang) => (
    <div key={lang.label} className="space-y-1">
      <div className="flex justify-between text-sm">
        <span>{lang.label}</span>
        <span>{lang.value}%</span>
      </div>
      <Progress value={lang.value} />
    </div>
  ))}
</div>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | `0` | Current progress value from `0` to `100`. |
| `max` | `number` | `100` | Maximum value. Change if your progress scale isn't 0–100. |
| `className` | `string` | — | Additional CSS classes. |
