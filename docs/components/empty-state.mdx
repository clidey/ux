`EmptyState` provides a consistent, centered layout for empty data scenarios. It shows an icon, title, description, and optional call-to-action. The content container uses `w-full max-w-[400px]` so it fills narrow containers gracefully while capping width in wider ones.


## Interactive example

<Specimen label="Empty State · Live example" padding="none">
  <EmptyStatePreview />

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo } from "./demo-shell";

export function EmptyStatePreview() {
  const [created, setCreated] = useState(false);
  return (
    <Demo hint="Create a first project to leave the empty state, then reset the example.">
      {created ? (
        <div className="ux-demo-form">
          <UX.Badge>Project created</UX.Badge>
          <h3>Untitled project</h3>
          <UX.Button variant="outline" onClick={() => setCreated(false)}>
            Reset example
          </UX.Button>
        </div>
      ) : (
        <UX.EmptyState
          title="A fresh start"
          description="Your next idea deserves a place to grow."
          icon={<UX.CatalogIcon name="folder-plus" size={36} />}
        >
          <UX.Button onClick={() => setCreated(true)}>Create a project</UX.Button>
        </UX.EmptyState>
      )}
    </Demo>
  );
}
```
</Specimen>

The code uses shared demo presentation helpers. Their complete source and styling are included in [the LLM build context](/llms.txt).


## Import

```tsx
import { EmptyState } from '@clidey/ux';
```

## Basic usage

```tsx
import { IconInbox as Inbox } from '@clidey/ux';

<EmptyState
  icon={<Inbox className="size-10 text-muted-foreground" />}
  title="No messages"
  description="When you receive a message, it will appear here."
/>
```

## Search empty state

```tsx
import { IconSearch as SearchX } from '@clidey/ux';

function NoResults({ query }: { query: string }) {
  return (
    <EmptyState
      icon={<SearchX className="size-10 text-muted-foreground" />}
      title={`No results for "${query}"`}
      description="Try different keywords or check your spelling."
    />
  );
}
```

## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `title` | `string` | Yes | Primary heading text. |
| `description` | `string` | Yes | Supporting descriptive text below the title. |
| `icon` | `ReactNode` | Yes | Icon or illustration shown above the title. |
| `children` | `ReactNode` | No | Optional call-to-action content (buttons, links). |
| `className` | `string` | No | Additional CSS classes on the container. |
