# Table

The `table.tsx` module provides a composable table. `TableBody` renders its rows normally by default; give the enclosing `Table` a `maxHeight` and `TableBody` automatically windows its rows so thousands of rows can be rendered without DOM overflow — no separate virtualized component required, and no risk of the header and body columns drifting out of alignment, since rows always stay in native table layout.

## Import

```tsx
import {
  Table,
  TableHeader,
  TableBody,
  TableFooter,
  TableHead,
  TableRow,
  TableCell,
  TableCaption,
  TableProvider,
  TableHeadRow,
} from '@clidey/ux';
```

## Virtualized table (large datasets)

Pass `maxHeight` to `Table` to make it scrollable. `TableBody` then automatically renders only the rows near the visible area, plus lightweight spacer rows for the rest:

```tsx
const COLUMNS = ['ID', 'Name', 'Email', 'Status'];
const rows = generateLargeDataset(10000); // e.g. 10,000 rows

<Table maxHeight={400}>
  <TableHeader>
    <TableHeadRow>
      {COLUMNS.map((col) => (
        <TableHead key={col}>{col}</TableHead>
      ))}
    </TableHeadRow>
  </TableHeader>
  <TableBody rowHeight={48} overscan={5}>
    {rows.map((row) => (
      <TableRow key={row.id}>
        <TableCell>{row.id}</TableCell>
        <TableCell>{row.name}</TableCell>
        <TableCell>{row.email}</TableCell>
        <TableCell><Badge>{row.status}</Badge></TableCell>
      </TableRow>
    ))}
  </TableBody>
</Table>
```

`rowHeight` is only an estimate used to compute which rows are near the viewport before their real height is measured — it accepts a `number` or a `(index: number) => number` function for variable-height rows. Actual rendered row heights are measured automatically and used once available, so `rowHeight` doesn't need to be exact.

## Cell with JSON preview

When a cell contains a large JSON object, `TableCell` renders an eye icon that opens a formatted JSON preview in a `Drawer`:

```tsx
<TableCell>
  {JSON.stringify(largeObject)}
</TableCell>
```

Overflow detection is automatic — if the content exceeds the cell width, a preview icon appears.

## Sub-components

| Component | Description |
| --- | --- |
| `Table` | Root `<table>` element. Accepts `maxHeight` to make the table scrollable and enable virtualization in `TableBody`. |
| `TableHeader` | `<thead>` section. |
| `TableBody` | `<tbody>` section. Renders all children normally, or virtualizes them when the enclosing `Table` has `maxHeight` set. |
| `TableFooter` | `<tfoot>` section. |
| `TableRow` | `<tr>` row element. |
| `TableHead` | `<th>` header cell. |
| `TableCell` | `<td>` data cell. Has overflow detection. |
| `TableCaption` | `<caption>` for the table. |
| `TableProvider` | Context provider used internally by `Table`. |
| `TableHeadRow` | Header row styled to match `TableRow`. |

### Table Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `maxHeight` | `number` | — | Caps the table's height and makes it scrollable. Required for `TableBody` to virtualize its rows. |

### TableBody Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `rowHeight` | `number \| ((index: number) => number)` | `40` | Estimated height of each row in pixels, used before the real height is measured. Only relevant when the enclosing `Table` has `maxHeight` set. |
| `overscan` | `number` | `3` | Number of rows to render above and below the visible area. Only relevant when virtualized. |
| `children` | `ReactNode` | — | `TableRow` elements, same as a plain table body. |
