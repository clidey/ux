Use catalog components for the icon itself. Use `Icon` when you need a consistent presentation surface around an SVG.

```tsx
import { Icon, IconSettings, IconDownload, Button } from '@clidey/ux';

<Icon icon={<IconSettings />} size={20} variant="subtle" />
<Icon icon={<IconSettings />} size={24} variant="solid" />
<Button variant="outline"><IconDownload /> Export</Button>
```

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo } from "./demo-shell";

export function IconPresentationPreview() {
  const [variant, setVariant] = useState<"plain" | "subtle" | "solid">("subtle");
  return (
    <Demo hint="Compare presentation variants while keeping the same catalog artwork.">
      <div className="ux-demo-row">
        {(["plain", "subtle", "solid"] as const).map((value) => (
          <UX.Button
            key={value}
            variant={variant === value ? "secondary" : "ghost"}
            onClick={() => setVariant(value)}
          >
            {value}
          </UX.Button>
        ))}
      </div>
      <div className="ux-demo-row">
        <UX.Icon icon={<UX.CatalogIcon name="star" />} variant={variant} size={32} />
        <UX.Icon icon={<UX.CatalogIcon name="folder" />} variant={variant} size={32} />
        <UX.Icon icon={<UX.CatalogIcon name="settings" />} variant={variant} size={32} />
      </div>
    </Demo>
  );
}
```

## Props

| Prop | Type | Default | Purpose |
| --- | --- | --- | --- |
| `icon` | SVG React element | Required | Element cloned with the chosen dimensions. |
| `size` | `number` | `24` | Width and height of the child SVG. |
| `variant` | `"plain"`, `"subtle"`, `"solid"` | `"plain"` | Plain icon, muted surface, or filled icon tile. |
| `className` | `string` | — | Additional classes on the wrapper span. |

`Icon` forwards its ref to the wrapping span and accepts span HTML attributes. Its child SVG is decorative. Put an accessible name on an icon-only button, or provide text beside a standalone status icon.

## Choosing an API

| Situation | API |
| --- | --- |
| Fixed React icon | `IconSearch`, `IconHome`, and other named catalog exports |
| Dynamic React icon | `CatalogIcon` with a validated catalog name |
| Background tile or consistent wrapper | `Icon` with a catalog element |
| Non-React markup or static assets | `@clidey/ux/icons` URL map or individual SVG files |

Read [The icon catalog](/guides/icons) for naming, alternative artwork, and asset handling.
