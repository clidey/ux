`Drawer` slides in from any screen edge (top, bottom, left, right). It's powered by the [Vaul](https://github.com/emilkowalski/vaul) library and supports drag-to-dismiss on mobile.


## Interactive example

<Specimen label="Drawer · Live example" padding="none">
  <DrawerPreview />

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo, Status, DemoIcon } from "./demo-shell";

export function DrawerPreview() {
  const [open, setOpen] = useState(false);
  const [goal, setGoal] = useState(12);
  return (
    <Demo hint="Open the drawer, change the weekly goal, then close it by dragging or using Done.">
      <UX.Drawer open={open} onOpenChange={setOpen}>
        <UX.DrawerTrigger>
          <UX.Button variant="outline">Set weekly goal</UX.Button>
        </UX.DrawerTrigger>
        <UX.DrawerContent>
          <div className="ux-demo-drawer-body">
            <UX.DrawerHeader>
              <UX.DrawerTitle>A little momentum</UX.DrawerTitle>
              <UX.DrawerDescription>
                Choose a weekly goal for this example workspace.
              </UX.DrawerDescription>
            </UX.DrawerHeader>
            <div className="ux-demo-row">
              <UX.Button
                variant="outline"
                size="icon"
                aria-label="Decrease goal"
                onClick={() => setGoal((n) => Math.max(1, n - 1))}
              >
                <DemoIcon name="minus" />
              </UX.Button>
              <span className="ux-demo-metric">{goal}</span>
              <UX.Button
                variant="outline"
                size="icon"
                aria-label="Increase goal"
                onClick={() => setGoal((n) => n + 1)}
              >
                <DemoIcon name="plus" />
              </UX.Button>
            </div>
            <UX.DrawerFooter>
              <UX.Button onClick={() => setOpen(false)}>Done</UX.Button>
            </UX.DrawerFooter>
          </div>
        </UX.DrawerContent>
      </UX.Drawer>
      <Status>{goal} tasks per week</Status>
    </Demo>
  );
}
```
</Specimen>

The code uses shared demo presentation helpers. Their complete source and styling are included in [the LLM build context](/llms.txt).


## Import

```tsx
import {
  Drawer,
  DrawerTrigger,
  DrawerContent,
  DrawerHeader,
  DrawerTitle,
  DrawerDescription,
  DrawerFooter,
  DrawerClose,
} from '@clidey/ux';
```

## Basic drawer (bottom, default)

```tsx
<Drawer>
  <DrawerTrigger>
    <Button variant="outline">Open drawer</Button>
  </DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Move Goal</DrawerTitle>
      <DrawerDescription>
        Set your daily activity goal.
      </DrawerDescription>
    </DrawerHeader>
    <div className="p-4">
      {/* content */}
    </div>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose>
        <Button variant="outline">Cancel</Button>
      </DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## Directional variants

Change the `direction` prop on the `Drawer` component to slide in from a different edge:

```tsx
{/* From the right — good for detail panels */}
<Drawer direction="right">
  <DrawerTrigger>
    <Button>Open right panel</Button>
  </DrawerTrigger>
  <DrawerContent className="h-full w-80">
    <DrawerHeader>
      <DrawerTitle>Details</DrawerTitle>
    </DrawerHeader>
    <div className="p-4">{/* content */}</div>
  </DrawerContent>
</Drawer>

{/* From the top */}
<Drawer direction="top">
  <DrawerTrigger>
    <Button>Open top panel</Button>
  </DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Notification center</DrawerTitle>
    </DrawerHeader>
  </DrawerContent>
</Drawer>
```

## Mobile bottom sheet

The default bottom-positioned drawer works great as a mobile action sheet:

```tsx
<Drawer>
  <DrawerTrigger>
    <Button size="icon" variant="ghost">
      <MoreVertical className="size-4" />
    </Button>
  </DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Actions</DrawerTitle>
    </DrawerHeader>
    <div className="p-4 space-y-2">
      <Button variant="ghost" className="w-full justify-start">
        <Edit className="size-4 mr-2" /> Edit
      </Button>
      <Button variant="ghost" className="w-full justify-start">
        <Share className="size-4 mr-2" /> Share
      </Button>
      <Button variant="ghost" className="w-full justify-start text-destructive">
        <Trash className="size-4 mr-2" /> Delete
      </Button>
    </div>
  </DrawerContent>
</Drawer>
```

## Sub-components

| Component | Description |
| --- | --- |
| `Drawer` | Root. Accepts `direction`, `open`, `onOpenChange`. |
| `DrawerTrigger` | Opens the drawer. Renders as its child automatically for ux components (`Button`, `Badge`, ...) and intrinsic elements, so no `asChild` is needed; pass `asChild` only for other ref-forwarding elements. See [Triggers and asChild](/triggers-and-aschild). |
| `DrawerPortal` | Renders drawer outside the DOM tree. Used internally. |
| `DrawerOverlay` | Backdrop layer using the `--backdrop` CSS token. Used internally. |
| `DrawerContent` | The sliding panel. |
| `DrawerHeader` | Top section with title/description. |
| `DrawerTitle` | Accessible heading. |
| `DrawerDescription` | Supporting text. |
| `DrawerFooter` | Bottom section for actions. |
| `DrawerClose` | Closes the drawer. Use `asChild`. |

### Drawer Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` | Side the drawer slides in from. |
| `open` | `boolean` | — | Controlled open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Called when open state changes. |
| `shouldScaleBackground` | `boolean` | `false` | Scales down the page background when open. |
