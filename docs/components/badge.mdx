`Badge` is a compact inline label used for status indicators, categories, version tags, and counts.


## Interactive example

<Specimen label="Badge · Live example">
  <BadgePreview />

```tsx
import { useState } from "react";
import * as UX from "@clidey/ux";
import { Demo, DemoIcon } from "./demo-shell";

export function BadgePreview() {
  const [variant, setVariant] = useState<"default" | "secondary" | "destructive" | "outline">(
    "default",
  );
  return (
    <Demo hint="Choose a treatment and see the badge change while keeping its readable label.">
      <div className="ux-demo-row">
        {(["default", "secondary", "destructive", "outline"] as const).map((x) => (
          <UX.Button
            key={x}
            size="sm"
            variant={variant === x ? "secondary" : "ghost"}
            aria-pressed={variant === x}
            onClick={() => setVariant(x)}
          >
            {x}
          </UX.Button>
        ))}
      </div>
      <UX.Badge variant={variant}>
        <DemoIcon name="check-circle" /> Ready to review
      </UX.Badge>
    </Demo>
  );
}
```
</Specimen>

The code uses shared demo presentation helpers. Their complete source and styling are included in [the LLM build context](/llms.txt).


## Import

```tsx
import { Badge } from '@clidey/ux';
```

## Variants

```tsx
<Badge>Default</Badge>
<Badge variant="secondary">Secondary</Badge>
<Badge variant="destructive">Destructive</Badge>
<Badge variant="outline">Outline</Badge>
```

| Variant | Use case |
| --- | --- |
| `default` | Primary category, active status |
| `secondary` | Neutral category, draft status |
| `destructive` | Error, blocked, or danger status |
| `outline` | Low-emphasis label, version tag |

## With icons

```tsx
import { IconCheckCircle as CheckCircle2, IconClock as Clock, IconXCircle as XCircle } from '@clidey/ux';

<Badge>
  <CheckCircle2 className="size-3" />
  Active
</Badge>

<Badge variant="secondary">
  <Clock className="size-3" />
  Pending
</Badge>

<Badge variant="destructive">
  <XCircle className="size-3" />
  Failed
</Badge>
```

## Common use cases

### Status labels

```tsx
function StatusBadge({ status }: { status: string }) {
  const variants = {
    active: 'default',
    pending: 'secondary',
    failed: 'destructive',
    draft: 'outline',
  } as const;

  return (
    <Badge variant={variants[status as keyof typeof variants] ?? 'outline'}>
      {status}
    </Badge>
  );
}
```

### Version tag

```tsx
<span className="font-medium">
  Authentication API <Badge variant="outline">v2.1</Badge>
</span>
```

### Count indicator

```tsx
<div className="flex items-center gap-2">
  <span>Notifications</span>
  <Badge>12</Badge>
</div>
```

## Render as link (asChild)

```tsx
<Badge>
  <a href="/changelog">v1.5.0</a>
</Badge>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline"` | `"default"` | Visual style. |
| `asChild` | `boolean` | `false` | Render as the child element. |
| `className` | `string` | — | Additional CSS classes. |
| `children` | `ReactNode` | — | Badge content. |
